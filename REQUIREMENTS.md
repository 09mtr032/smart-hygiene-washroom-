# Requirements

## Hardware
- Arduino Mega 2560
- IR sensor
- 16x2 I2C LCD
- Soil moisture sensor
- Servo motor
- DC water pump
- Relay module
- 2 push buttons
- Buzzer
- Breadboard and jumper wires
- Suitable external power supply

## Software
- Arduino IDE
- Wire library
- LiquidCrystal_I2C library
- Servo library
